# NarraDock

A framework for producing, reviewing, and publishing audio and video from scripts.

NarraDock is a public personal product maintained in this repository. The product is in pre-alpha development; a working production or publication service is not yet available.

## Direction

- Audio-only publishing is a first-class workflow, independent of video rendering.
- Shared tooling is separate from project-specific scripts, assets, credentials, and runtime records.
- Generation, quality checks, human review, external transfer, and publication are separate operations.
- Development uses newly authored neutral examples and synthetic tests.

Implementation and detailed documentation are introduced through reviewed pull requests. Repository visibility is not a content-publication approval. A software license has not yet been selected.
